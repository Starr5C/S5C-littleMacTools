# MacTools

存放一些由 AI 协作构建的 macOS 效率小工具。

## 工具列表

### [S5C-LittleSideBar](S5C-LittleSideBar/)

为 macOS 台前调度设计的预留式窗口最大化工具。它通过系统快捷指令将当前窗口贴合显示器可用工作区，并按屏幕类型在左侧保留一小段相对宽度，不进入系统全屏，也不依赖第三方窗口管理软件。

### [S5C-LittleLittleArc](S5C-LittleLittleArc/)

当前版本 `0.1.0`。通过快捷指令接收网址，在 `~/Applications` 生成不内置浏览器的网页 App，并将目标地址交给 macOS 当前默认浏览器；支持精确页面或网站主页、自动图标、受管更新和敏感 URL 参数保护。项目采用本地 ad-hoc 签名，不保存 Cookie 或登录态，版本规则见 [S5C-LittleLittleArc/VERSIONING.md](S5C-LittleLittleArc/VERSIONING.md)。
