# S5C-LittleSideBar

S5C-LittleSideBar 是一个面向 macOS 台前调度的轻量窗口工具。它通过快捷指令把当前前台窗口放大到所在显示器的可用工作区，同时在左侧保留一条可见区域，方便继续看到和切换台前调度中的其他窗口。它不会进入系统全屏，也不依赖第三方窗口管理软件。

本机快捷指令显示名为“右侧最大化（保留台前调度）”，默认全局快捷键为 `⌃⌥⌘M`。

## 当前参数

- 内建屏左侧预留：可用宽度的 4.42%；
- 外接屏左侧预留：可用宽度的 3.125%；
- 边缘误差容忍：2 个逻辑点。

脚本通过系统显示器标识区分内建屏和外接屏，不依赖显示器名称；预留宽度根据当前显示器的 `visibleFrame.width` 动态计算，因此改变分辨率或缩放设置后仍保持相近视觉比例。需要调整时，修改 `S5C-LittleSideBar.jxa` 顶部 `CONFIG` 中的两个比例值，并把更新后的完整脚本重新粘贴到快捷指令的“文本”动作中。

## 创建快捷指令

1. 打开“快捷指令”，新建快捷指令并命名为“右侧最大化（保留台前调度）”。
2. 添加“文本”动作，把 `S5C-LittleSideBar.jxa` 的完整内容粘贴进去。
3. 添加“运行 Shell 脚本”动作，脚本填写 `/usr/bin/osascript -l JavaScript`。
4. 将“输入”设为上一步的“文本”，传递方式设为“到 stdin”。
5. 打开快捷指令详情，添加键盘快捷键 `⌃⌥⌘M`。

请通过键盘快捷键运行。若直接在“快捷指令”App 中点击运行，前台窗口可能变成“快捷指令”自身，脚本会主动停止并提示。

## 首次授权

1. 在“快捷指令 → 设置 → 高级”中启用“允许运行脚本”。
2. 运行一次快捷指令。
3. 如果 macOS 请求“自动化”或“辅助功能”权限，请允许“快捷指令”控制 System Events。
4. 若没有自动出现提示，前往“系统设置 → 隐私与安全性 → 辅助功能”，启用“快捷指令”。

脚本只读取当前窗口、显示器工作区和缩放信息，并设置窗口的位置与尺寸；不会读取窗口内容、保存历史位置或联网。

## 工作机制

脚本读取 macOS 的 `NSScreen.visibleFrame`，让系统自动排除菜单栏、常驻 Dock 和刘海等不可用区域。它以窗口与各显示器的重叠面积判断目标显示器，因此窗口跨屏时也能稳定选择主要所在屏幕；随后按内建屏或外接屏的比例计算左侧预留，并通过辅助功能接口调整焦点窗口的位置与尺寸。

窗口尺寸使用 macOS 逻辑坐标而非物理像素。Retina 缩放、显示器分辨率或排列变化不会让规则绑定到某个固定像素值。

## 目标区域的含义

窗口右侧与当前显示器可用工作区右边缘对齐；顶部位于菜单栏下方；Dock 常驻底部时，窗口底边位于 Dock 上沿。`NSScreen.visibleFrame` 会根据当前菜单栏、Dock 位置和自动隐藏设置动态返回可用工作区。

## 常见失败提示

- “当前前台应用是快捷指令”：先选中目标窗口，再按全局快捷键。
- “当前窗口处于系统全屏”：先退出系统全屏；本工具不会主动改变全屏状态。
- “窗口本身不可缩放”：该应用使用固定窗口尺寸，脚本不会强制绕过。
- “没有读取到显示器信息”：脚本不在已登录的图形桌面中运行。

## 验证

运行纯函数自检：

    osascript -l JavaScript S5C-LittleSideBar.jxa --self-test

本机双屏 GUI 验收结果见 `TEST_REPORT.md`。测试辅助代码位于 `tests/`，它只读取显示器和 Finder 窗口的几何信息。

## 文件说明

- `S5C-LittleSideBar.jxa`：可独立运行、也可嵌入快捷指令的主脚本；
- `TEST_REPORT.md`：当前双显示器环境下的真实窗口验收记录；
- `tests/WindowGeometryProbe.swift`：读取显示器与窗口几何信息的辅助探针。

## 系统要求

- macOS，且系统支持“快捷指令”和辅助功能窗口控制；
- 已登录的图形桌面会话；
- 给“快捷指令”授予自动化和辅助功能权限。
